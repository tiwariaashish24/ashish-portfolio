## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/tiwariaashish24/ashish-portfolio.git
   ```

2. Move into the project directory:

   ```bash
   cd ashish-portfolio
   ```

3. Install dependencies using the package manager supported by the project:

   ```bash
   npm install
   ```

4. Start the development server using the script defined in `package.json`. For many Vite projects, this is:

   ```bash
   npm run dev
   ```

5. Open the local URL printed in your terminal.

> Note: If the project uses a different package manager or scripts, follow the configuration in `package.json`.
